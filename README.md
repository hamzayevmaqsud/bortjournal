# Бортжурнал

Личный ежедневник: еда, учёба по IT, вопросы на повторение, зал, шаги, статистика.
Фронтенд без сборки плюс маленький сервер на Node.js без зависимостей. У каждого пользователя
свой аккаунт (логин и пароль), записи хранятся на сервере в папке `data/`.

## Как запустить

Нужен Node.js 18 или новее.

```
npm start
```

Открыть http://localhost:3333, зарегистрироваться или войти. Сервер слушает всю локальную сеть
и при старте печатает адрес вида `http://192.168.x.x:3333` — по нему журнал открывается
с телефона в той же Wi-Fi сети, с теми же данными.

Настройки через переменные окружения: `PORT` (по умолчанию 3333), `HOST` (`127.0.0.1`, чтобы
открыть только на этом компьютере), `DATA_DIR` (где хранить данные).

## Данные

- `data/users.json` — логины и хеши паролей (scrypt), сами пароли не хранятся.
- `data/sessions.json` — активные входы (cookie живёт 90 дней).
- `data/state/<логин>.json` — все записи пользователя.

Папка `data/` не попадает в git. Для резервной копии достаточно скопировать её или сделать
«Настройки → Экспорт JSON». Если в браузере остались записи из прежней версии без аккаунтов,
после первого входа журнал предложит перенести их в аккаунт.

Если одно и то же открыто на двух устройствах, сервер не даст старой вкладке затереть свежие
данные: она подтянет актуальную версию и попросит повторить последнее изменение.

## Разделы

- **Сегодня.** Лента дня (06:00–24:00) с отметками еды, учёбы и зала, карточки по разделам,
  заметка и настроение. Стрелки у даты листают дни назад, чтобы дописать пропущенное.
- **Еда.** Приёмы пищи с ккал и БЖУ. Введённые блюда запоминаются и появляются как чипы для
  записи в одно нажатие.
- **Учёба.** Занятие = тема, направление, минуты, тезисы (по одному в строке) и, по желанию,
  пары `Вопрос => Ответ`.
- **Вопросы.** Каждый день собираются из тезисов по интервальному повторению (1, 2, 5, … дней,
  коэффициент меняется от ответов «не помню / частично / помню»). Типы: пропуск слова, раскрыть
  тезис, пересказать тему. Если в настройках есть API-ключ Anthropic, кнопка
  «Переформулировать через Claude» заменяет локальные формулировки на вопросы от модели;
  расписание повторений при этом не меняется.
- **Зал.** Тренировка с упражнениями в текстовом формате, одна строка на упражнение:
  `Жим лёжа 3x8 60` (3 подхода по 8 на 60 кг), `Присед 4x6 80, 1x4 90`, `Подтягивания 3x10`,
  `Бег 20 мин`. Рекорды и объём считаются сами.
- **Шаги.** Шаги и вес за день, график за 30 дней, динамика веса за 90.
- **Цель.** При первом входе анкета: пол, возраст, рост, вес, телосложение, опыт силовых,
  активность на неделю и цель (похудеть / держать / набрать мышцы, темп, желаемый вес).
  По ней считаются калории, белок, жиры и углеводы, темп в кг в неделю и срок до цели.
  Каждый понедельник журнал спрашивает активность на неделю и вес и пересчитывает цели.
  Блок «По факту» по записанным весу и еде показывает реальный тренд, реальный расход
  и прогноз, если продолжать так же.
- **Статистика.** Период 7 / 30 / 90 дней, KPI, карта активности на 16 недель (в каждой клетке
  четыре квадрата: еда, учёба, зал, шаги), графики по разделам.
- **Настройки.** Аккаунт (смена пароля, выход), цели, имя, ключ Claude, экспорт / импорт / полная очистка.

## Файлы

- `server.js` — сервер: раздаёт страницу, регистрация, вход, сессии, хранение данных.
- `index.html` — каркас и навигация.
- `styles.css` — винтажная ретро-тема: плоский крем, сплошные плитки (тёмно-синий, оранжевый, шалфей, горчица, персик), крупные цифры, нижняя панель, адаптивная раскладка.
- `plan.js` — формулы: обмен веществ (Mifflin–St Jeor / Katch–McArdle), расход, дефицит и профицит, белок, прогноз веса, тренд.
- `app.js` — вход, синхронизация с сервером, страницы, вопросы, графики, вызов Claude API.

Шрифты (Rubik, Onest) подгружаются с Google Fonts; без интернета
подставятся системные.
