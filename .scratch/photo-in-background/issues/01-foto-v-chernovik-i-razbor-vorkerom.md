# 01: Фото уходит в черновик приёма, воркер его разбирает

**What to build:** человек отправляет фото еды и сразу получает ответ: черновик приёма в состоянии «в очереди». Отдельный процесс-воркер забирает черновик, разбирает фото через ИИ и переводит черновик в «готов» с позициями, вопросами и комментарием. Человек видит свои черновики и их состояние. Лимит ИИ списывается один раз, при отправке.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Отправка фото отвечает сразу черновиком «в очереди», ИИ при этом не вызывается
- [ ] Один проход воркера переводит черновик в «готов» с позициями, вопросами и комментарием
- [ ] Черновики человека и один черновик можно получить; чужой черновик — 404
- [ ] Без Pro — 402, без ключа ИИ — 503, кривое фото — 400, как у нынешнего распознавания
- [ ] Лимит ИИ списан ровно один раз
- [ ] Воркер — отдельная точка входа; модули обрабатывают свои задания через свой публичный модуль
